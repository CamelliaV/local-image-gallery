# 本地图片浏览器
[![en](https://img.shields.io/badge/lang-EN-red.svg)](https://github.com/CamelliaV/local-image-gallery/blob/master/README.md) [![中文](https://img.shields.io/badge/lang-简中-green.svg)](https://github.com/CamelliaV/local-image-gallery/blob/master/README.CN.md)


## 简介
简易本地图片浏览器

特性:
- 浏览显示多个目录的图片，包括子目录
- 拖拽改变图片位置
- 方向键与滚轮切图
- 方向键缩放
- 图片与动图格式支持
- 删除功能（仅浏览器）

注: a vibe-coding project

## 开始使用
- 本地克隆install后运行 `npm run start`
- [部署Demo](https://camelliav-gallery.netlify.app/)
